## About the Project
This project is a JavaScript worksheet designed to understand scope and hoisting concepts through output prediction and explanations.

## Topics Covered
- var Hoisting
- let Hoisting
- Block Scope
- Function Scope
- const Declaration

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
- 21-scope-and-hoisting.html – Contains the complete worksheet with HTML, CSS, and JavaScript in a single file.
- README.md – Project documentation.

## How to Run
1. Open the HTML file in VS Code.
2. Run it using Live Server.
3. Read the questions and their explanations.
4. Click the Show Summary button.

## Learning Outcome
Learn how JavaScript handles variable declarations, scope, and hoisting.
