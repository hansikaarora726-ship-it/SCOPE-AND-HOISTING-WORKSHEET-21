Scope and Hoisting Worksheet

Predict the output of the following JavaScript concepts.

Question 1: var Hoisting

What will be the output?

console.log(a);
var a = 10;

Answer: undefined

Explanation: The var declaration is hoisted to the top, but its value is assigned later.

Question 2: let Hoisting

What will happen?

console.log(b);
let b = 20;

Answer: ReferenceError

Explanation: let is hoisted but cannot be accessed before initialization.

Question 3: Block Scope

What will be the output?

{
    let x = 30;
}
console.log(x);

Answer: ReferenceError

Explanation: A let variable is accessible only inside its block.

Question 4: Function Scope

What will be the output?

function test() {
    var y = 40;
    console.log(y);
}
test();

Answer: 40

Explanation: A var variable declared inside a function is accessible within that function.

Question 5: const Declaration

What will happen?

const z = 50;
z = 60;
console.log(z);

Answer: TypeError

Explanation: A const variable cannot be reassigned after initialization.
